# 陶笛汇

面向高净值人群的移动端财富管理与活动服务原型。

当前仓库以 `code_artifact.html` 为核心，配合共享 AI 模块验证以下闭环：

- 首页内容建立认知与信任
- 严选承接营养保健品与香港高端医疗服务
- 首页两位老师 AI 分身对话、我的 AI 五富评估
- 活动详情 -> 准入校验 -> 特批码 -> 支付模拟
- 支付成功后同步订单记录、我的行程、电子票
- 会员等级、五富徽章、会员核心特权联动
- 设置内承接投资者认证、账号信息与安全设置

### 各期交付重点

- 一期：完成内容播放、活动报名支付、订单票据与消费记录的主闭环；建设账户、内容、活动、订单等基础接口。验收重点为支付幂等、订单与行程一致、权限与隐私基础。底部为直播、活动、我的三个入口，四专栏保留，不开发文章频道。
- 二期：复用一期账户和支付能力，增加严选商品与医疗服务预约、地址与履约状态、会员与徽章计算、内容筛选及消息提醒。验收重点为累计消费与徽章独立计算、预约确认流程、商品履约、会员准入和特批码；增加严选 Tab。医疗预约需人工或机构确认，不代表自动获得诊疗服务。
- 三期：基础业务稳定后接入 AI。先完成内容授权、老师演讲转录与知识库检索、文字问答，再完成授权声音与语音轮次；照片形象先上线，实时数字人驱动单独评估。同步交付五富自评、智能客服、认证与售后退款。验收重点为回答引用与边界、语音停止与权限、评估数据隔离、退款幂等与进度。
- 每期保留前期能力，并以验收结果进入下一期；不承诺固定“一期一个月”。当前页面是功能原型，不代表真实支付、人工客服、模型、授权声音或生产接口已接入。

## 产品逻辑检查

`20261122-logic18` 修复了本地原型内确认的状态与流程问题：

- 手机演示验证码仅接受 `888888`，绑定发送时的手机号，5 分钟有效；登录成功和退出后失效。退出清理旧子页导航。
- 活动按实际结束日期关闭报名；多日活动在结束前仍列入当前行程。提交时与模拟支付完成时均复查资格，跨期返回预约页重新计算权限。
- 联系电话和设置邮箱校验；活动订单保存联系人与备注。特批解锁不清空表单。
- 活动与商品支付防重复提交、离页取消；消费按订单号记账，同时增加总财富值和对应赛道徽章，会员等级仍独立按总额计算。
- 补齐历史订单与消费关联；账单简称使用明确赛道分类。初始订单、账单总额和五富徽章分类金额一致。
- 退款按订单号精确回收账单与行程，重复退款不重复扣减；已退款服务不再点亮权益。商品退款保留商品订单列表。
- 电子票只从已确认活动行程生成，不按标题猜测；待审核、退款和取消订单不可出票或签到。签到仅在活动日期内，更新行程与订单状态，重复签到无副作用，仍保留原票弹窗与父页。
- 医疗付款后状态为待机构确认。售后联系客服实际打开专属客服入口，改期申请避免重复记录。
- 投资者认证为第三期自愿资料演示，不拦截购买，也不声称完成真实身份核验。退款、签到、推送均区分本地演示与真实服务。
- AI 入口补充分期校验，原声结束清理播放状态；未提交评估保留本次草稿，校验存储报告日期与答案。

业务验证：`node business-validation.cjs` 覆盖记账幂等、独立徽章、同名订单精准退款与权益回收、退款分期限制、活动日期、联系电话、票券状态、签到幂等和验证码错误/换号/过期。

浏览器回归覆盖三期手机主要路径、跨期历史前进权限复查、连续免费提交、特批表单保留、医疗支付及退款、评估草稿、电子票父页、退出导航、基础回放与语音生命周期。

原型边界：订单与账号使用内存演示数据，刷新后重置；评估可保存在当前浏览器。未接入真实短信、微信身份、支付退款、票券核销、服务方审批、人工客服、系统推送或生成式 AI。不同手机号不是独立真实账户，生产版本必须由服务端完成身份隔离、权限校验、支付对账及退款政策审核。

## 手机页面导航

- 一级页面保留底部 Tab，严选作为独立栏目不显示返回首页按钮；进入完整业务子页面后隐藏首页头部、期次条和 Tab，仅显示当前页面及顶部“返回”。
- 按用途混合使用页面与弹窗：电子票、徽章权益说明、特批码输入使用轻量弹窗，保留背后的当前页面和位置；预约、严选详情结算、专栏观看、AI 对话、订单、设置和评估仍使用多级页面。
- 首页 → 专栏回放合集 → 观看页；返回观看页的上一层仍为该专栏，不直接跳首页。
- 活动 / 日历 → 活动详情 → 确认预约；需要时在预约页上弹出特批码输入框，取消或解锁后仍回到该预约。返回保留父页面的滚动、日历选择和表单输入。
- 严选 → 商品或医疗服务详情 → 确认订单；返回详情不丢失其来源分类，浏览器前进可恢复未提交表单。
- 首页 → 老师 AI 文字对话 → 语音通话；语音是独立三级页面，返回文字页保留会话并停止识别和音频。语音页直接播放纯音频，浏览器前进恢复语音页时不会自动播放。文字页与通话页均无素材试听入口。
- 我的 → AI 五富评估 → 分身咨询；咨询返回仍为评估结果。我的 → 设置 → 修改密码 / 认证；我的 → 订单 / 行程 → 售后页面；查看电子票直接弹出电子票卡片，关闭仍停留原行程或订单。
- 支付成功后清理旧预约、结算页面，再显示结果页；“查看订单”进入“我的”的订单记录，返回落到“我的”，不重新进入旧支付表单。
- 模拟支付等待期间返回会取消本次演示支付，恢复按钮且不生成订单；再次前进仍可保留表单并重新提交。真实支付接入后需以服务端交易状态为准。
- 页面内返回、弹窗关闭、浏览器返回和前进共用 History API；同页不重复压栈。URL 中 `#page=...` 标识当前页面，`#dialog=...` 标识临时弹窗。弹窗支持关闭按钮、遮罩点击与浏览器返回，背后页面不可误触；关闭后恢复原入口焦点。刷新原型时回到所属期次首页，未完成表单不承诺跨刷新保存。
- 手机全宽、桌面最大 448px；内容区域独立滚动，适配安全区与可视高度，输入框使用 16px 字号避免手机自动缩放。不再使用遮罩式弹窗承载完整业务流程；短消息仍为 Toast。保留旧 DOM ID 和兼容函数名，仅为避免破坏业务引用。
- 弹窗验证覆盖三期电子票、二三期权益说明和特批解锁，以及关闭、遮罩、浏览器返回/前进、背后页面保留。320px 电子票可查看，关闭按钮可见。

## 业务规则摘要

### AI 原型边界

- 两位分身是独立对话的本地规则演示，支持快捷问题、自由文字输入、上下文追问及切换后保留本次会话。
- 语音通话的每轮用户识别文字与分身文字回复同步到该老师的聊天记录。挂断或切回打字时显示最新一轮，再次打开或切换老师后仍保留本次会话；不混入另一位老师或客服的记录。
- 每条分身回答下方提供“复制”和“朗读”。复制只针对该条正文；朗读可停止，选择其他回答会停止旧朗读。老师卡片不放全局朗读或更换形象入口。
- “语音对话”位于分身老师卡片右上角，底部不重复放入口。语音模式按“说话 → 说完了”操作，点击说完后用对应老师音频模拟 AI 回复，保持照片与“正在回复”状态显示，不播放视频、不自动朗读规则回答；保留静音、结束通话与切回打字，不提供试听和重播素材操作。
- 麦克风识别完成或失败都不会自动播放，必须点击“说完了”；权限未开或浏览器不支持识别时仍可演示回复播放。文字模式的语音转文字仍需确认后发送。切换老师、返回上一页、页面隐藏时停止识别与播放。
- APP 右上角保留“专属客服”：一二期为商务经理联系入口，三期增加报名、订单售后及会员徽章智能咨询演示。客服不打开老师分身，不混用分身聊天记录；两位老师的首页 AI 入口仅在三期开放。
- 语音输入使用 `SpeechRecognition` / `webkitSpeechRecognition`，需要支持的浏览器、麦克风权限与 HTTPS（localhost 也可）。语音识别可能由浏览器厂商的网络服务处理，本原型不保存音频；不支持或权限被拒绝时提供文字回退。朗读使用 `speechSynthesis` 系统声线，不是老师本人声线，回答不代表老师观点。
- 两位老师形象固定使用用户下载文件夹的 `王牧笛.jpeg` 与 `陶矜.webp`，首页与文字、语音模式均展示，不提供用户导入或更换老师照片的功能。
- 技术实现：回复使用用户提供视频第 5 至 20 秒提取的 `.m4a` 纯音频，内容不随问题变化，不是生成式回答或声线克隆。源视频分别是王牧笛的油价话题与陶矜的认知成长话题。面向产品经理的通话界面模拟目标功能，不展示“原声开启 / 试听原声 / 重播原声 / 预录老师原声 / 非实时回答”等实现说明；这些边界仅保留于技术文档。
- 目前是照片形象展示，不是口型驱动或动作驱动的数字人；状态波形只表示识别与声音播放，不代表老师视频。
- 技术实现：通话音频仍用固定片段模拟回答，文字回复沿用本地规则生成，尚非音频逐字转写。正式接入模型后须用同一回答驱动文字与语音。
- `20261122-chat21` 浏览器验证两位老师各两轮语音问答、挂断后新消息可见、重新进入记录保留、逐条复制实际剪贴板内容、朗读切换及停止、无形象更换入口和320px布局；语音识别与系统朗读使用测试桩，回复音频使用实际文件。
- 商用前需取得两位老师的肖像、声线和内容授权，再接入演讲视频转录、知识检索、真实模型、授权声音及数字人驱动；当前未接入这些服务。
- AI 五富评估按香港保险、港美股、高端医疗、全球房产、家族办公室作答，每项准备度示例值为 20 / 55 / 85；结果为自评，不代表投资适当性、专业建议或会员徽章等级。
- 评估仅保存选择项与日期到当前浏览器，三期共用；重新评估不会修改财富值、等级或徽章。
- 评估操作固定在页面底部，报告可继续咨询陶矜老师 AI 分身，按低分赛道提供规划提示；返回报告保留结果。
- 严选产品、价格、支付均为原型示例，不代表已上线商品或真实医疗预约。

## 部署说明

本项目可直接部署到 Vercel。8080 当前被其他项目占用，本地预览使用 8081，不停止其他项目服务。

关键点：

- 根入口为 `index.html`
- 实际原型页为 `code_artifact.html`
- `ai-experience.js` 与 `ai-experience.css` 是三期共用的 AI / 严选模块，部署时需一并包含
- `mobile-navigation.js` 与 `mobile-navigation.css` 必须一并部署，负责所有二级、三级页面的导航和手机布局
- `watch-experience.js` 与 `watch-experience.css` 必须一并部署，负责直播与回放的播放和互动界面
- `column-experience.css` 必须一并部署，负责四专栏二级页的视觉呈现
- `assets/teachers/` 中的照片、`.m4a` 音频与 `.mp4` 参考片段需随项目部署；AI 回复仍仅播放音频，`.mp4` 用于观看页播放演示
- 若部署后首页打不开，优先检查根入口是否被正确识别

验证：`node phase-validation.cjs` 检查三期门控、移动导航接入、纯音频资源和脚本语法；手机浏览器实测覆盖 390×844 与 320×568、专栏观看返回、预约支付闭环、支付等待返回取消、结算输入与首页滚动保留、AI 语音返回和前进、评估咨询返回报告、日历详情返回、设置认证返回。

本地预览服务使用 Python 标准库并支持视频 HTTP Range / 206，请勿替换为不支持分段请求的普通 http.server，否则部分浏览器无法跳转进度。它仅用于本地演示，生产部署仍使用静态托管/CDN。

观看页补充验证：三期分别检查直播/回放入口、16:9 播放区、基础播放器播放/暂停与进度、无倍速/章节/收藏/回放标签、讨论发送、点赞、离页暂停、浏览器前进以及专栏父页面返回；320px 无横向溢出，直播输入栏保持可见。
