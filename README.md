# 五富汇

高净值人群导向的高端商务智库与活动服务平台原型。

当前仓库是一个以 `code_artifact.html` 为核心的单文件移动端原型，重点验证以下闭环：

- 内容建立认知与信任
- 频道承接赛道化内容消费
- 活动详情 -> 报名 -> 支付模拟
- 支付成功后同步订单、账单、行程
- 会员等级、五富徽章、核心特权三套体系并行

## 项目结构

- `code_artifact.html`
  核心原型文件，包含页面结构、样式、数据和交互逻辑。

- `index.html`
  根入口文件，部署到 Vercel 后访问根路径时会自动跳转到原型页。

- `wangmudi-banner.png`
  首页直播主视觉素材。

## 当前产品结构

底部导航共 4 个一级模块：

- `直播`
- `频道`
- `活动`
- `我的`

另有首页重点入口：

- `牧笛严选`（二期商城预留）

## 核心能力

### 1. 内容引擎

- 首页直播 Banner
- 重磅直播预告
- 精华回放专题
- 四个独立专栏
- 赛道频道内容浏览

### 2. 活动引擎

- 活动列表
- 活动详情
- 双门槛校验（会员等级 + 徽章）
- 支付流程模拟
- 支付成功后数据联动

### 3. 会员经营引擎

- 会员等级体系
- 五富资产版图（雷达图）
- 会员核心特权点亮
- 全景权限说明弹窗

### 4. 账户沉淀引擎

- 我的行程
- 订单中心
- 账单流水
- 设置入口

## 业务规则摘要

### 会员等级

会员等级仅由总消费决定：

- 尊享会员
- 白金会员
- 黄金会员
- 黑金VIP会员

### 五富徽章

五富徽章仅由单类服务消费决定，赛道固定为：

1. 香港保险
2. 港美股
3. 高端医疗
4. 全球房产
5. 家族办公室

### 核心特权

核心特权支持两类点亮来源：

- 会员等级点亮
- 已购服务点亮

当前视觉规则：

- 已点亮 = 金色
- 未点亮 = 灰色
- 点击仅弹说明，不跳转

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 8899
```

然后打开：

```text
http://localhost:8899/
```

## 部署说明

本项目可直接部署到 Vercel。

关键点：

- 根入口为 `index.html`
- 实际原型页为 `code_artifact.html`
- 若部署后首页打不开，优先检查根入口是否被正确识别
