# 陶笛汇

面向高净值人群的移动端财富管理与活动服务原型。

当前仓库以 `code_artifact.html` 为核心，配合共享 AI 模块验证以下闭环：

- 首页内容建立认知与信任
- 严选承接营养保健品与香港高端医疗服务
- 首页两位老师 AI 分身对话、我的 AI 五富评估
- 活动详情 -> 准入校验 -> 特批码 -> 支付模拟
- 支付成功后同步订单记录、我的行程、电子票
- 会员等级、五富徽章、会员核心特权联动
- 设置内承接投资者认证、账号信息与安全设置

## 项目结构

- `code_artifact.html`
  核心原型文件，包含页面结构、样式、数据和交互逻辑。

- `index.html`
  根入口文件，三期预览选择页，可直接进入第一期 / 第二期 / 第三期任一版本。

- `ai-experience.js` / `ai-experience.css`
  三期共用的严选目录、AI 分身对话与五富评估交互及样式。

- `assets/teachers/`
  用户提供的两位老师照片，以及各 15 秒的原声参考视频。原始下载文件不修改。

- `wangmudi-banner.png`
  首页直播主视觉素材。

## 三期预览

原型通过 URL 参数 `?phase=1|2|3` 呈现三个不同版本，默认 `phase=3`（完整版）。2026-11-21 的产品调整优先于原 PDF 中的文章、频道及商城分期安排：

- 三期共同：直播与回放、牧笛严选、活动支付、我的、王牧笛老师与陶矜老师 AI 分身、AI 五富评估
- 第一期 极简基础版：基础观看、严选购买与医疗预约、行程与订单；活动不设会员和徽章双门槛
- 第二期 内容与会员服务：增加会员等级、五富徽章、特权、直播预告、活动日历及通知
- 第三期 交易与服务扩展：增加投资者认证和售后退款

访问方式：

```text
http://localhost:8081/code_artifact.html?phase=1&v=20261121-ai6
http://localhost:8081/code_artifact.html?phase=2&v=20261121-ai6
http://localhost:8081/code_artifact.html?phase=3&v=20261121-ai6
```

页面顶部提供期次切换按钮，可在三个版本间直接跳转。

## 当前产品结构

当前原型包含 4 个一级页面：

- `直播`
- `严选`
- `活动`
- `我的`

其中：

- `我的` 页面聚焦 AI 五富评估、会员身份、资产版图、会员核心特权、行程、订单和设置
- `严选` 为牧笛严选，展示益生菌、鱼油、香港高端体检与专科咨询示例；营养品下单需填收货地址，医疗服务需填期望预约日期
- 文章、旧频道和专栏已移除；录播归入直播首页“精选回放”的“全部回放”二级页

## 核心能力

### 1. 内容引擎

- 首页直播 Banner
- 重磅直播预告
- 精华回放专题
- 回放二级页及时间、主题筛选
- 王牧笛老师与陶矜老师 AI 分身入口

### 2. 活动引擎

- 活动列表
- 活动详情
- 双门槛校验（会员等级 + 徽章）
- 特批码解锁当前活动资格
- 支付流程模拟
- 支付成功后同步订单、行程、电子票

### 3. 会员经营引擎

- 会员等级体系
- 五富资产版图（雷达图）
- 会员核心特权点亮
- 顶部 VIP 统一承接权益规则说明

### 4. 账户沉淀引擎

- 我的行程
- 活动电子票
- 订单记录（活动 / 商品 Tab）
- 设置
- 投资者认证
- 邮箱与密码管理

## 业务规则摘要

### AI 原型边界

- 两位分身是独立对话的本地规则演示，支持快捷问题、自由文字输入、上下文追问及切换后保留本次会话。
- 支持文字聊天、语音转文字（确认后发送）及沉浸语音模式：大幅形象、转录字幕、回答朗读、静音、结束语音与切回打字。切换老师、关闭弹窗、页面隐藏时停止识别与播放，避免跨老师串话或后台录音。
- 语音输入使用 `SpeechRecognition` / `webkitSpeechRecognition`，需要支持的浏览器、麦克风权限与 HTTPS（localhost 也可）。语音识别可能由浏览器厂商的网络服务处理，本原型不保存音频；不支持或权限被拒绝时提供文字回退。朗读使用 `speechSynthesis` 系统声线，不是老师本人声线，回答不代表老师观点。
- 两位老师默认形象已使用用户下载文件夹的 `王牧笛.jpeg` 与 `陶矜.webp`，首页与文字、语音模式均展示。也支持导入 JPG / PNG / WebP 替换，压缩后保存在当前浏览器，三期共用；禁用存储时仅本次会话有效。
- “老师原声”单独播放用户提供视频第 5 至 20 秒的片段，保留原声；不会把这些原声片段当作 AI 回答，也未用于声线克隆。源视频分别是王牧笛的油价话题与陶矜的认知成长话题。
- 目前是照片形象展示，不是口型驱动或动作驱动的数字人；状态波形只表示识别与朗读，不代表老师视频。
- 商用前需取得两位老师的肖像、声线和内容授权，再接入演讲视频转录、知识检索、真实模型、授权声音及数字人驱动；当前未接入这些服务。
- AI 五富评估按香港保险、港美股、高端医疗、全球房产、家族办公室作答，每项准备度示例值为 20 / 55 / 85；结果为自评，不代表投资适当性、专业建议或会员徽章等级。
- 评估仅保存选择项与日期到当前浏览器，三期共用；重新评估不会修改财富值、等级或徽章。
- 评估操作固定在弹窗底部，报告可继续咨询陶矜老师 AI 分身，按低分赛道提供规划提示。
- 严选产品、价格、支付均为原型示例，不代表已上线商品或真实医疗预约。

### 会员等级

会员等级仅由总消费决定：

- 尊享会员
- 白金会员
- 黄金会员
- 黑金VIP会员

### 五富徽章

五富徽章仅由单类服务消费决定，赛道固定为：

1. 香港保险
2. 港美股
3. 高端医疗
4. 全球房产
5. 家族办公室

### 核心特权

核心特权支持两类点亮来源：

- 会员等级点亮
- 已购服务点亮

当前视觉规则：

- 已点亮 = 金色
- 未点亮 = 灰色
- 点击仅弹说明，不跳转

## 部署说明

本项目可直接部署到 Vercel。8080 当前被其他项目占用，本地预览使用 8081，不停止其他项目服务。

关键点：

- 根入口为 `index.html`
- 实际原型页为 `code_artifact.html`
- `ai-experience.js` 与 `ai-experience.css` 是三期共用的 AI / 严选模块，部署时需一并包含
- `assets/teachers/` 中的照片与参考视频需随项目部署，否则形象和原声片段无法加载
- 若部署后首页打不开，优先检查根入口是否被正确识别
