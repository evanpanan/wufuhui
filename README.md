# 陶笛汇

面向高净值人群的移动端财富管理与活动服务原型。

当前仓库以 `code_artifact.html` 为核心，采用单文件原型方式验证以下闭环：

- 首页内容建立认知与信任
- 频道承接五大赛道内容消费
- 活动详情 -> 准入校验 -> 特批码 -> 支付模拟
- 支付成功后同步订单记录、我的行程、电子票
- 会员等级、五富徽章、会员核心特权联动
- 设置内承接投资者认证、账号信息与安全设置

## 项目结构

- `code_artifact.html`
  核心原型文件，包含页面结构、样式、数据和交互逻辑。

- `index.html`
  根入口文件，部署到 Vercel 后访问根路径时会自动跳转到原型页。

- `wangmudi-banner.png`
  首页直播主视觉素材。

## 当前产品结构

当前原型包含 5 个一级页面：

- `首页`
- `频道`
- `活动`
- `我的`
- `牧笛严选`

其中：

- `我的` 页面聚焦会员身份、资产版图、会员核心特权、我的行程、订单记录、设置
- `牧笛严选` 为商城原型区，商品订单能力已在订单记录中预留

## 核心能力

### 1. 内容引擎

- 首页直播 Banner
- 重磅直播预告
- 精华回放专题
- 四个独立专栏
- 赛道频道内容浏览

### 2. 活动引擎

- 活动列表
- 活动详情
- 双门槛校验（会员等级 + 徽章）
- 特批码解锁当前活动资格
- 支付流程模拟
- 支付成功后同步订单、行程、电子票

### 3. 会员经营引擎

- 会员等级体系
- 五富资产版图（雷达图）
- 会员核心特权点亮
- 顶部 VIP 统一承接权益规则说明

### 4. 账户沉淀引擎

- 我的行程
- 活动电子票
- 订单记录（活动 / 商品 Tab）
- 设置
- 投资者认证
- 邮箱与密码管理

## 业务规则摘要

### 会员等级

会员等级仅由总消费决定：

- 尊享会员
- 白金会员
- 黄金会员
- 黑金VIP会员

### 五富徽章

五富徽章仅由单类服务消费决定，赛道固定为：

1. 香港保险
2. 港美股
3. 高端医疗
4. 全球房产
5. 家族办公室

### 核心特权

核心特权支持两类点亮来源：

- 会员等级点亮
- 已购服务点亮

当前视觉规则：

- 已点亮 = 金色
- 未点亮 = 灰色
- 点击仅弹说明，不跳转

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 8080
```

然后打开：

```text
http://localhost:8080/
```

## 部署说明

本项目可直接部署到 Vercel。

关键点：

- 根入口为 `index.html`
- 实际原型页为 `code_artifact.html`
- 若部署后首页打不开，优先检查根入口是否被正确识别
